Nexo - Tienda de Tecnología

Descripción

Este proyecto consiste en el desarrollo de un sitio web de una tienda de productos tecnológicos. Su objetivo es ofrecer una experiencia de navegación sencilla e intuitiva, permitiendo a los usuarios conocer los productos disponibles, consultar ofertas y acceder a la información de contacto.

El sitio fue desarrollado utilizando HTML y CSS, incorporando JavaScript para funcionalidades interactivas.


Instrucciones de uso

Ingresar al sitio web mediante el enlace publicado.

Utilizar la barra de navegación para acceder a las diferentes secciones:

Inicio: página principal.

Productos: catálogo de productos disponibles.

Ofertas: productos con descuentos y promociones.

Contacto: información para comunicarse con la tienda.

Navegar por las distintas secciones e interactuar con los elementos disponibles.
